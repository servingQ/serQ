# Lean regressions

Programs on which the Lean semantics (`lean/Serq/Exec.lean`) must give the
interpreter's answer. They are cases differential testing found
(`scripts/lean_drt.py`), or constructs its random cases do not reach.

- `<name>.sq`: the program, with a batch arrival.
- `<name>.sessions.json`: the sessions, as preset attributes.
- `<name>.ir.json`, `<name>.out.json`: generated by
  `scripts/lean_regress.py --bless` (the IR with the sessions explicit, and
  `serq run`'s observations and preemptions on it).
- `lean/Serq/Regress.lean`: generated from both by
  `scripts/gen_lean_oracle.py`, one theorem per program.

`make lean` checks that `Regress.lean` is current; `make drt` checks that the
recorded answers are still the interpreter's.
